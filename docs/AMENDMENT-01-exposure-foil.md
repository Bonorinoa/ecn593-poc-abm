## Motivation

One foil (causal forest) confounds two failure sources: (i) SUTVA
architecture — the forest cannot represent interference at all; (ii) one-world
conditioning — no estimator consumes the calibration set. A referee will ask
"why not the estimator designed for interference?" Adding an exposure-mapped,
design-based estimator (Aronow–Samii style) separates the two: whatever gap
remains after the *correct* estimator runs is attributable to calibration
uncertainty alone. It also serves as a positive control for the harness.

## Critical design fact (drove every choice below)

π₂ (degree targeting) is **deterministic** — `assign()` always picks the same
80 hubs. Design-based inference needs a randomization mechanism with known
assignment probabilities. π₁ (simple random sample without replacement,
k = 80 of N = 800) is such a mechanism; π₂ is not. Therefore **E2 lives on the
π₁ panel**, and each estimator is compared against the honest set *of its own
estimand*. This is not a limitation to hide — it is itself a result:
policy-relevant targeted assignments are often deterministic, and the
design-based toolkit simply does not reach them.

## E2 definition (to be frozen verbatim into §9)

- **Design:** π₁, SRSWOR(k = ceil(0.10·N) = 80). First- and second-order
  inclusion probabilities exact (finite-population formulas).
- **Exposure map:** g_i = (D_i, s_i) with s_i = Σ_{j∈N(i)} D_j / k_i.
  Frozen strata:
  - S1: D_i = 1
  - S0a: D_i = 0, s_i = 0          (unexposed control)
  - S0b: D_i = 0, 0 < s_i < 0.25   (lightly exposed)
  - S0c: D_i = 0, s_i ≥ 0.25       (heavily exposed)
  Thresholds fixed a priori, not data-driven.
- **Cell-size guard (declared fallback):** if any stratum has < 20 agents in a
  replication, merge S0b into S0c for ALL replications of that world and log it.
- **Estimands (Hájek contrasts of stratum mean outcome):**
  - δ_dir = mean(S1) − mean(S0a)      (direct-effect analogue)
  - δ_spill = mean(S0c) − mean(S0a)   (pure spillover — HEADLINE for overlay;
    a SUTVA estimator cannot even express it)
- **Variance:** randomization-based (HT/Hájek variance under SRSWOR with exact
  second-order inclusion probabilities; conservative variant preferred).
- **Outcomes:** s from m ∈ {m₁ oracle, m₂ survey} exactly as §9 (m₃ excluded
  by §8 admission).
- **Seeds:** panels reuse SEED_RUN_BASE offsets; no new entropy sources.

## New comparison objects (extends §7)

- Θ_exp = { δ_spill(c) : c ∈ NROY }, empirical [L,U] over survivors.
  Implementation: during moment passes, additionally record per-rep stratum
  means (scalars — negligible storage); θ₁ and θ₂ images come free from the
  existing three-arm evaluation.
- θ_true versions of δ_dir, δ_spill at c₀ via the R = 200 paired-rep machinery.

## Pre-registered findings (extension of §10)

- **F-OVERCONF-E2:** I_E2 ⊂ interior of Θ_exp and/or excludes δ_true.
- **F-HONEST-E2:** I_E2 covers Θ_exp.
- **Positive control (validity gate, not a finding):** at m₁ (oracle), if
  E2's point estimate misses δ_true(c₀) beyond its CI, the harness is broken —
  stop, fix, re-run. The "good" estimator MUST pass where everything is known.

## Hand-example test (pedagogical contract)

Path graph A–B–C–D, treat {B}: s = (0, ½, ½, 0) for (A,B,C,D);
strata: A→S0a, B→S1, C→S0c (½ ≥ 0.25), D→S0a. Docstring states the arithmetic.

## Known risks

1. **Stratum thinness:** mean degree ≈ 4, 10% treated ⇒ E[s_i | control] ≈ 0.4
   but dispersion is wide; guard above handles degenerate cells. Check cell
   counts in the first wave log.
2. **Discretization arbitrariness:** appendix robustness tick, declared now —
   recompute with threshold 0.5; report whether F-* conclusions flip.
3. **Cross-foil comparability:** forest targets θ₂-flavored quantities, E2
   targets δ's; the overlay figure therefore shows each interval against its
   OWN honest set (Θ_hm for the forest, Θ_exp for E2) — never against each
   other's.

## Cost estimate

Zero new simulation cost for Θ_exp (piggybacks on moment passes). E2 fit is
O(N) arithmetic per rep. Total added wall-clock: seconds. Added code: ~80 lines
+ tests.
